# ClipForge

ClipForge is a personal video-editing and posting tool used only by its owner, Darian Danciu, for the GospelFuel channels. It runs on the owner's own Windows PC and is not offered to anyone else.

## What it does

- Turns the owner's long videos into short vertical clips with captions, music and edits.
- Publishes the finished clips to the owner's own accounts: YouTube Shorts (through the YouTube Data API), the GospelFuel Facebook Page and @gospelfuelclips Instagram account (through Meta's APIs) and TikTok (through TikTok's Content Posting API), at times the owner chooses.
- Reads back the owner's own recent uploads to confirm each post went live.

## Google user data

When the owner connects their YouTube channel, ClipForge asks Google for two permissions:

- `youtube.upload`, to upload the owner's finished Shorts with their title, description, tags and publish time;
- `youtube.readonly`, to show which channel is connected and to read back the channel's recent uploads, so it can confirm each Short went live.

That data stays on the owner's PC, is used only for these features, and is never shared or sold. ClipForge's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.
